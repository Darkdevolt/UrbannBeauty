# Logo

Déposez votre logo ici sous le nom **`logo.png`** (fond transparent recommandé, ~200×80px).

Il s'affichera automatiquement :
- dans l'en-tête du site public
- dans le pied de page du site public
- dans la barre latérale de l'espace admin
- sur la page de connexion admin

Aucune autre modification n'est nécessaire — le code détecte le fichier tout seul. Tant qu'il est absent, le logo texte "Urbann Beauty" reste affiché à la place.
